# MINEDEX Stock Exchange 2.0 ⛏️📈

The official Minecraft Stock Trading Competition web portal built for E-Cell entrepreneurship simulation events.

## Features
- **Authentic Minecraft GUI Aesthetic:** Pixelated fonts (`Press Start 2P`), obsidian inventory containers, and classic item slot styling.
- **Secure Admin Access:** Password-protected organizer panel (`Ecell2627`).
- **Real-Time Cross-Tab Synchronization:** Uses `BroadcastChannel` and `localStorage` so timers, rounds, breaking news, and price sliders sync instantly across all open browser windows without a backend server.
- **0% Baseline Price Volatility Sliders:** Precise market manipulation anchored to original base prices with instant preset buttons (`-50%`, `-25%`, `0%`, `+25%`, `+50%`).
- **Sound Effects & Chaos Events:** Web Audio API synth sound effects and random market chaos triggers.

## Quick Start
1. Clone the repository or download the ZIP.
2. Open `index.html` directly in any web browser, or host it on **GitHub Pages**, **Vercel**, or **Netlify**.
3. Open one tab as **Organizer Admin** (Password: `Ecell2627`) and other tabs as **Trader Teams** to watch real-time sync in action!
